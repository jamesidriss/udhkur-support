Confidentialité — Udhkur

Éditeur : James Ripoll. Dernière mise à jour : 16 octobre 2026. Contact : ripolljames@hotmail.com.

Udhkur ne demande aucun compte. Vos compteurs, objectifs personnels, favoris, séquences, rappels et historiques sont conservés sur votre appareil. Aucun service publicitaire ou outil d'analyse tiers n'est intégré.

Les widgets accèdent à un instantané local partagé avec l'application. L'Apple Watch échange des données avec vos appareils Apple pour rapprocher les activités enregistrées hors ligne.

La synchronisation iCloud est facultative. Lorsqu'elle est activée, les données nécessaires à la synchronisation sont transmises à votre espace privé iCloud par les services Apple. L'application doit rester utilisable lorsque ce service est indisponible.

Les rappels utilisent les notifications locales d'Apple et nécessitent votre autorisation. Le mode discret masque le contenu de l'invocation dans les notifications. La prononciation synthétique, lorsqu'elle est disponible, utilise la voix arabe de l'appareil.

Les apparences facultatives permanentes et le soutien financier facultatif passent par les achats intégrés Apple. Les droits des apparences sont vérifiés localement avec StoreKit ; les achats de soutien ne donnent aucun droit cosmétique. Le soutien ne débloque aucune fonctionnalité. Apple traite le paiement selon ses conditions de confidentialité.

Vous pouvez consulter et gérer les données locales depuis l'application. Vous pouvez exporter vos données ou choisir « Effacer mes données » dans les réglages. L’effacement exige une confirmation, supprime les données locales et désactive la synchronisation. Il ne supprime pas les copies conservées sur vos autres appareils ou dans iCloud. Réactiver les échanges peut restaurer l’activité conservée ailleurs.

Pour toute question concernant vos données ou cette politique, écrivez à ripolljames@hotmail.com. N’envoyez pas votre historique personnel sauf si vous souhaitez explicitement le communiquer pour une demande d’assistance.
