Le comptage fonctionne sans connexion, sans compte et sans achat. Pour utiliser les rappels, autorisez les notifications dans les réglages de votre appareil. Le refus de cette autorisation n'empêche pas de compter.

La synchronisation peut être différée lorsque votre Apple Watch est déconnectée ou lorsque iCloud est indisponible. Ne supprimez pas les données d'un appareil avant la fin du rapprochement.

Les objectifs et repères haptiques personnels sont des aides de comptage. Ils ne constituent pas des prescriptions religieuses. Seuls les éléments dont les textes, références et droits ont été validés peuvent entrer dans le corpus religieux de production.

Pour signaler un problème, relevez la version de l'application, le modèle d'appareil, la version du système et les étapes permettant de reproduire le problème. Évitez de transmettre votre historique personnel.

Pour signaler une correction de contenu, relevez l'identifiant de l'invocation et sa référence exacte. Une proposition de correction doit être examinée avant publication.

Contact support et confidentialité : ripolljames@hotmail.com.

Pour restaurer les apparences permanentes, ouvrez Réglages > Apparence > Restaurer les achats avec le compte Apple ayant effectué l’achat. Un remboursement peut retirer l’apparence ; le compteur et les historiques restent disponibles. Les achats peuvent être désactivés dans les versions de test. Leur disponibilité est indiquée dans l’application.
